# Análisis de Datos - Aurora Borealis

Proyecto desarrollado como parte del curso **Fundamentos de Análisis de Datos - MICITT PROCOMER**.

## Tema
Crecimiento de la comunidad de clientes de Aurora Borealis.

## Pregunta de investigación
¿Qué estrategias de promoción generan un mayor aumento de miembros en el grupo de WhatsApp de Aurora Borealis?

## Objetivo
Identificar cuáles estrategias de promoción ayudan a aumentar de forma más efectiva la cantidad de miembros del grupo de WhatsApp del emprendimiento.
